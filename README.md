## 🌌 About

**Astrobot** is a space-themed conversational chatbot designed to make learning about the universe more interactive.

Users can ask questions about topics such as:

- 🌍 Planets
- ⭐ Stars
- 🌌 Galaxies
- 🚀 Space missions
- 🛰️ Satellites
- 🌑 The Moon
- ☀️ The Solar System
- 🔭 Astronomy and astrophysics

The chatbot processes user messages through **Google Dialogflow** and returns an appropriate conversational response.
